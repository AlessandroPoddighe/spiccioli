# Spiccioli

Web app **personale** per analizzare le mie spese: si collega ai conti bancari
italiani tramite l'API AIS di [Enable Banking](https://enablebanking.com) (sola
lettura), storicizza saldi e movimenti su [Supabase](https://supabase.com) e li
mostra in una PWA pensata per iPhone e PC.

- Architettura e scelte: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md), [`docs/adr/`](docs/adr/README.md)
- Configurazione passo passo (solo browser): [`docs/SETUP.md`](docs/SETUP.md)
- Convenzioni e comandi: [`CLAUDE.md`](CLAUDE.md)

Nessun segreto e nessun dato bancario sono presenti in questo repository.
